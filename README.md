# AiOS CAD na Androida

AiOS CAD to lokalna pracownia prostych brył 3D. Zmieniaj wymiary, zapisuj rewizje, importuj STEP i eksportuj STEP, STL lub 3MF. Wersja 0.9.0 to wczesny dostęp dla telefonów ARM64 z Androidem 8 lub nowszym.

- [Pobieranie i instalacja](https://aios-cad-prywatnosc.spiffy-cow-4659.chatgpt.site/pobierz.html)
- [Podpisane APK i materiały do wydania](https://github.com/bagno97/aios-cad-releases/releases)
- [Polityka prywatności](https://aios-cad-prywatnosc.spiffy-cow-4659.chatgpt.site/)
